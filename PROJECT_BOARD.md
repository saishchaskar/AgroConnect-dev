# AgroConnect Project Board

This file documents the proposed GitHub Project board for the AgroConnect PWA initiative.

## Project name
AgroConnect PWA Roadmap

## Board columns
1. Backlog
2. Planned
3. In Progress
4. Review
5. Done

## Labels
- `pwa`
- `frontend`
- `backend`
- `ai`
- `rag`
- `ml`
- `mobile`
- `accessibility`
- `performance`
- `documentation`
- `good first issue`
- `help wanted`

## Suggested workflow
- Start issues in `Backlog` when they are identified.
- Move them to `Planned` once scoped and prioritized.
- Move to `In Progress` when active development starts.
- Move to `Review` once implementation is ready for validation.
- Mark `Done` when merged and verified.

## Priority areas
- PWA installability and offline resilience
- Image capture and diagnosis workflow
- AI and RAG integration quality
- Farmer-friendly multilingual UX
- Field usability and accessibility
- Deployment and contributor onboarding

This board complements the issue backlog in `GITHUB_ISSUES.md`.
