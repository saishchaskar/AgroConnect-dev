# Contributing to AgroConnect

Thanks for your interest in contributing to AgroConnect.

This repository contains work related to crop disease detection, AI-based recommendations, and Retrieval-Augmented Generation (RAG) for agricultural guidance. Contributions in machine learning, data preparation, frontend work, prompt design, deployment, and documentation are all welcome.

## Contribution areas

- Dataset improvement and image quality review
- Model evaluation and benchmarking
- RAG tuning and retrieval enhancements
- Mobile app and UI improvements
- Multilingual support and localization
- Documentation and reproducible setup

## Getting started

1. Fork the repository.
2. Clone it locally.
3. Create a feature branch for your work.
4. Review the project README and relevant notebooks or application folders.
5. Open a pull request with a clear summary of the change.

## Good first issues

Look for issues labeled:
- good first issue
- help wanted
- documentation
- machine-learning
- enhancement

## Contribution guidelines

- Keep changes focused and easy to review
- Document model assumptions or data changes clearly
- Add reproducible scripts where possible
- Test changes when relevant, especially for pipelines and data processing
- Be clear about assumptions, environment dependencies, and model versions

## Issue tracker

A contributor-ready list of project issues is available in `GITHUB_ISSUES.md`.
